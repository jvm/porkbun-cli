# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting:

https://github.com/jvm/porkbun-cli/security/advisories/new

Include the affected command or component, reproduction steps, impact, and any suggested mitigation. Do not include real Porkbun credentials, domain authorization codes, account data, or other secrets.

You should receive an acknowledgment within seven days. A fix and disclosure timeline will depend on severity and reproducibility.

## Supported Versions

Security fixes are provided for the latest released version.
